# Local images

Put your image files here so the site loads them **instantly** from GitHub Pages — no Supabase wait.

## Folder layout (matches CMS keys)

| What | Drop file here |
|------|----------------|
| Headshot / profile photo | `about/headshot.jpg` |
| Hero case card (01) | `hero-cards/case-01.jpg` |
| Hero design card (01) | `hero-cards/design-01.jpg` |
| Projects stack cover | `case-studies/credigo.jpg` |
| Case study hero | `cases/credigo/hero.png` |
| Case study screens | `cases/credigo/screen-01.png` |
| Design project cover | `design/lumea-essence.jpg` |
| Life / products | `life/...`, `products/...` |

## Steps

1. Add your file to the matching path above (create subfolders as needed).
2. Optional: register overrides in `js/local-images.js` if the filename differs.
3. Commit and push — images go live with the site.

**Profile picture** (navbar, meet card, project cards): use `about/headshot.jpg`.

After you add files, hard refresh the site once.
